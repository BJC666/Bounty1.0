## 4.2 关键代码实现

### Agent主循环 (internal/agent/agent.go)

```go
func (a *Agent) Run(ctx context.Context, input string) error {
    sess := a.Session()
    sess.Add(provider.Message{Role: "user", Content: input})
    for step := 0; step < a.maxSteps; step++ {
        // 1. 流式调用LLM
        ch, _ := a.prov.Stream(ctx, messages, schemas, opts)
        // 2. 收集响应(text/reasoning/toolCalls)
        // 3. 无工具调用→最终答案
        if len(toolCalls) == 0 { return nil }
        // 4. 执行工具(只读并行，写操作顺序)
        results := a.executeTools(ctx, toolCalls)
        // 5. 护栏检查+压缩
        a.checkGuardrails(toolCalls, results)
        a.maybeCompact(sess)
    }
}
```

## 4.4 部署方案

### 单二进制部署
```bash
CGO_ENABLED=0 go build -ldflags="-s -w" -o bounty.exe ./cmd/bounty/
# → ~29MB单文件，无运行时依赖
```

### 一键启动(Windows)
```bat
双击 start.bat → 自动启动DeVET后端 + Bounty TUI
双击 启动网页.bat → 自动打开浏览器到聊天界面
```

### 环境要求
- Go 1.25+ (仅构建时需要)
- Python 3.10+ (DeVET后端)
- DeepSeek API Key (或Anthropic/Ollama)
