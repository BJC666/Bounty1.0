# 六、附录

## 6.1 软件架构图

```
Bounty 1.0/
├── cmd/bounty/main.go        ← CLI入口(6命令)
├── internal/
│   ├── agent/                ← Agent引擎(循环/会话/压缩/护栏/子代理)
│   ├── boot/                 ← 组装层(15子系统→Controller)
│   ├── control/              ← 传输无关会话驱动器
│   ├── tool/builtin/         ← 12个内置工具 + 5 DeVET + 3 子代理 = 20
│   ├── provider/             ← 4个LLM Provider
│   ├── channel/              ← 5个消息通道
│   ├── memory/               ← 4级记忆+漂移检测+注入扫描
│   ├── store/                ← SQLite+FTS5
│   ├── skill/                ← 技能系统+Curator生命周期
│   ├── hook/                 ← 9事件Hook
│   ├── permission/           ← 权限Gate+Bash模式匹配
│   ├── sandbox/              ← OS沙箱+Docker沙箱
│   ├── mcp/                  ← MCP客户端(JSON-RPC)
│   ├── checkpoint/           ← Git-free快照+回退
│   ├── cli/tui.go            ← Hermes风格TUI
│   └── serve/                ← Web仪表盘+聊天页面
└── competition/              ← 竞赛文档
```

## 6.2 核心代码片段

### 权限Gate (internal/permission/gate.go, 130行)

四级姿态决策 + Bash模式匹配 + 文件系统保护

### Fleet并行子代理 (internal/agent/fleet.go, 100行)

2-64并行 + 写路径冲突预检 + 写者信号量调度

### DeVET集成 (internal/tool/builtin/devet.go, 240行)

5工具 × ~50行/工具，HTTP调用+JSON解析+自然语言输出
