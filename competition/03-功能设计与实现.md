# 三、功能设计与实现

## 3.1 核心功能

### 3.1.1 AI对话引擎

- 流式响应处理，支持reasoning(DeepSeek R1)和thinking(Claude)
- 8类API错误自动分类+指数退避重试
- 3级Token压缩(soft/compact/force)
- Credential Pool多Key轮转

### 3.1.2 工具系统(20个)

| 类别 | 工具 | 说明 |
|------|------|------|
| 文件 | read_file/write_file/edit_file/grep/glob | 只读并行、32KB截断 |
| 执行 | bash/browser | 120s超时、Docker沙箱、CDP协议 |
| 搜索 | web_search(DDG)/web_fetch/code_index | 免费搜索API、5语言正则索引 |
| 管理 | todo_write/remember | 无副作用任务列表、注入扫描记忆 |
| 子代理 | task/read_only_task/fleet | 深度限制、路径冲突检测 |
| 验证 | devet_*(5个) | DeVET委托链验证集成 |

### 3.1.3 权限安全

四级运行时姿态 + Bash模式匹配白/黑名单 + 文件系统保护 + OS沙箱

### 3.1.4 多通道支持

Terminal REPL / Webhook / HTTP API / Telegram Bot / Gateway SSE

## 3.2 DeVET集成功能

Bounty通过5个专用工具调用DeVET的REST API:

1. `devet_health` — 检查DeVET后端状态
2. `devet_build_scenario` — 构建3智能体Trading DAO委托链
3. `devet_verify_chain` — 验证链完整性(7步递归检查)
4. `devet_list_attacks` — 列出8种攻击类型
5. `devet_simulate_attack` — 模拟攻击+显示检测结果和归因

**验证流程**:
```
用户: "帮我验证这个委托链是否安全"
Bounty → devet_build_scenario → 构建链
Bounty → devet_verify_chain → 7步递归验证
Bounty: "✅ 验证通过，3个智能体全部可信"
```
