# 二、技术架构与创新

## 2.1 整体架构

Bounty采用**Controller模式**的三层架构：

```
┌─────────────────────────────────┐
│  前端层: TUI / Web / Desktop    │ ← 三个前端共享一个Controller
├─────────────────────────────────┤
│  控制层: Controller + Boot      │ ← 传输无关的会话驱动器
├─────────────────────────────────┤
│  核心层: Agent引擎 + 工具系统    │ ← Go原生编译，高性能
│  ├── 12个内置工具               │
│  ├── 4个LLM Provider             │
│  ├── 5个消息通道                 │
│  ├── 9事件Hook系统               │
│  └── DeVET验证集成(5工具)        │
├─────────────────────────────────┤
│  基础设施: SQLite+FTS5 / 权限 /  │
│  沙箱 / MCP客户端 / 环境探针     │
└─────────────────────────────────┘
```

## 2.2 关键创新点

### 创新1: 8层前缀缓存稳定性

针对DeepSeek的prefix-cache机制，系统性地保证API请求前缀字节不变：
1. System Prompt构建一次永不修改
2. Tool Schema注册时canonicalize+排序
3. Skills索引仅name+desc(上限4000字符)
4. 环境探针结果缓存到磁盘
5. 记忆更新走turn tail不动前缀
6. 后台任务通知走turn tail
7. Hook上下文走turn tail
8. Plan/Goal标记走turn tail

**效果**: 成本降低50-90%（实测435M token可达到99.82%缓存命中率）

### 创新2: Fleet并行子代理 + 路径冲突检测

2-64并行子代理，写操作前预检write_paths重叠→全部拒绝或全部启动，最多3个并发写者。**同类产品均不具备此能力**。

### 创新3: DeVET委托链验证集成

首次将学术研究成果(DeVET, 信息安全学报投稿)产品化：Bounty作为AI引擎调用DeVET的REST API，实现多智能体委托链的构建→验证→攻击模拟→归因分析全流程。8种攻击100%检测率，0.024ms验证延迟。

**P4-1 全链路自动验签（2026-08-13）**：
- 每次 task/fleet 子代理完成后，Bounty 自动把（宿主身份、子代理身份、结果 sha256 承诺、工具调用次数、写入文件清单）镜像为 DeVET 委托链（`/chain/mirror`）：每个子代理一条密封 DelegationGrant + CompositeProof，承诺绑定子代理最终结论。
- 随即自动执行 7 项递归验证（根身份→根链连续性→授权哈希封存→有效期→深度策略→AID 绑定→证明验证→API 上限），结果以【DeVET 验证】一节追加进子代理结构化摘要，父代理所见即验签结果。
- 攻击注入自动归因：`/chain/tamper` 可替换任意委托节点的证明后复验，`blame_path` 精确到 `delegation[i] → 子代理名`，故障类型（grant_tampered/policy_violation/subagent_proof_invalid/expired 等）与证明层 AID 哈希失配细节完整回传。
- Web 控制台新增「🛡️ 验证链」可视化面板：展示宿主→各子代理的承诺、工具调用数、写入文件、逐节点 ✓/✗ 状态与责任归因路径，SSE 实时刷新。
- 验收（Eval F1–F6，8 类攻击抽样 6 类）：qwen3.8-max 实测 6/6 PASS——每题均实际调用 devet_build_scenario + devet_simulate_attack，正确报告 DETECTED=YES、实际 fault_type 与 blame 首节点，检测率 100% 且归因正确。

## 2.3 技术选型

| 技术 | 选型 | 理由 |
|------|------|------|
| 核心语言 | Go 1.25 | 原生并发、单二进制编译、高性能 |
| LLM接入 | OpenAI兼容协议 + Anthropic Messages API | 覆盖DeepSeek/Claude/Ollama/OpenAI |
| 存储 | SQLite + FTS5 | 零配置、全文搜索、WAL并发 |
| 终端UI | Bubbletea + Lipgloss | Go原生TUI框架、Hermes风格主题 |
| Web前端 | 内嵌SPA + SSE | 无额外依赖、实时流式推送 |
| MCP协议 | JSON-RPC 2.0 stdio | 标准协议、工具自动发现 |
