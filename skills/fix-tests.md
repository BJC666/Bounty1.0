# 测试修复流程

1. 复现：单独重跑失败用例（-run 精确过滤），确认失败稳定可复现、排除并行串扰。
2. 分类：编译错 / 断言错 / 超时 / 环境依赖（端口占用、外网、特定系统）。
3. 定位：读失败断言与堆栈；若偶发，重点查共享状态、时间依赖、并行测试互相污染。
4. 修复：先确认测试预期正确再改实现；若预期本身有误（环境假设失效），修正断言并注释原因。
5. 回归：单包连跑 3 次 + 全量跑一次；禁止「改测试让红变绿」式掩盖实现 bug。
