# 上下文管理纪律

- 及时沉淀：跨轮需要的事实写入记忆（remember/项目记忆库），不靠重复口述。
- 控制体积：读文件按需读取与裁剪；大输出用头尾保留策略；不把整个仓库灌入上下文。
- 防泄露：不在上下文与日志中出现密钥/令牌；敏感值只存在于运行时变量。
- 压缩时机：接近阈值前主动 compact，保留任务目标、已做决策、关键文件改动、未完成事项与错误教训五要素。
- 防漂移：每轮结束时核对当前目标与原目标是否一致；无关话题及时回正。
