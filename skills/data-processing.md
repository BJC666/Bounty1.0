# 数据处理规范

- 先看数据：行数、列类型、空值比例、唯一值分布；抽样检查后再写处理逻辑。
- 可复现：固定随机种子、记录输入文件哈希、处理参数写入产物元信息。
- 校验：每步转换后断言行数/类型/取值范围；异常行单独落盘供排查，不静默丢弃。
- 内存：大数据流式处理或分块，避免一次性载入内存；中间结果落盘可断点续跑。
- 交付：输出带表头的明确格式（CSV/TSV 或库表），附字段说明与来源口径。
