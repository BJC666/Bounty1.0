# 构建与发布流程

- 可复现构建：锁定依赖版本（锁文件）；构建前清环境并记录工具链版本。
- 产物校验：发布前核对构建产物哈希、大小、关键符号/字符串；签名产物并校验签名。
- 版本化：语义化版本（major.minor.patch）；变更日志记录每个版本的功能与修复。
- 发布：灰度/金丝雀→全量；发布前备份上一版本并准备一键回滚方案。
- 事后：监控错误率/延迟/资源；异常立即按预案回滚并保留现场日志。
