# 安全审计清单（攻击者视角）

- 输入边界：所有外部输入（HTTP 参数/文件/环境/上游响应）是否校验类型、长度、白名单。
- 注入类：SQL/命令/模板/LDAP 拼接点；文件路径是否可穿越（../、绝对路径、符号链接）。
- 认证授权：会话固定、弱随机、缺失鉴权的接口、越权（水平/垂直）访问对象引用。
- 凭据：硬编码密钥、日志泄露、错误信息回显堆栈、调试接口外露。
- 依赖与配置：已知漏洞版本、默认口令、过宽的文件权限、危险的系统调用。
- 输出：存储型/反射型 XSS、敏感信息出现在响应或静态资源中。

输出：【资产与信任边界】【威胁路径】【风险等级】【修复建议】，只做审查不实施攻击。
