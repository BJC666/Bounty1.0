# 日志分析方法

1. 定范围：按时间窗、请求 ID、会话 ID、服务名过滤，先缩小到最小相关集合。
2. 字段化：统一提取时间/级别/来源/事件字段；结构不统一时先归一化再分析。
3. 时间线：按时间排序还原事件先后；对比正常样本与异常样本的差异。
4. 关联：同请求 ID 串联跨服务日志；错误前后的上下文（前一条成功日志常是关键）。
5. 结论：用日志证据支撑结论，标注样本量与时间范围；没有日志证据时不臆断。
