# 代码搜索策略

- 先按文件名/目录名定位，再按符号搜索；优先精确关键词而非泛化词。
- 搜索调用链：符号定义 → 引用点 → 上层调用逐层回溯；接口多实现时先找注册/装配点。
- 搜索配置项：配置键名 + 默认值 + 读取点三方一致核对。
- 用仓库索引工具（repo_map/代码索引）先看结构，避免盲目递归搜索。
- 命中多条时按修改时间与测试覆盖判断主路径；读代码顺序：定义 → 使用 → 测试。
