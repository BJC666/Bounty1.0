# 网络问题分层排查

从近到远逐层验证：
1. 本机：服务是否监听（端口占用查询）、防火墙是否放行、回环地址连通性。
2. DNS：解析结果是否正确、是否命中污染/劫持、hosts 与系统配置顺序。
3. 路由：到网关/下一跳是否通、路由表是否正确、跨网段策略。
4. 远端：握手超时还是被拒（区分端口关闭与过滤）、TLS 证书与版本协商。
5. 出口：代理配置、NAT、限速与丢包（连续探测统计）。

每层记录证据（命令输出+时间）再进入下一层；改配置前备份原值。
