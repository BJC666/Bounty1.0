# 技术文档生成规范

- 结构：一句话简介 → 快速开始（安装/运行 2-3 条命令）→ 核心概念 → 配置项表格 → 常见问题。
- 所有命令、路径、配置键使用代码块或行内代码格式；示例必须真实可运行（先自己跑通再写进文档）。
- 面向「第一次接触的人」：不假设读者知道术语，首次出现的缩写给全称。
- 变更代码后同步更新对应文档章节；文档中不写虚假的未实现功能。
- 中文文档注意：代码标识符保留原文，叙述用中文，避免生硬直译。
