# 数据库设计规范

- 命名：表名复数蛇形、主键自增 id、外键 <表>_id；时间统一带时区。
- 约束：非空与唯一约束放数据库层（不依赖应用层校验）；金额用整数分或 decimal。
- 索引：按真实查询模式建索引；联合索引最左前缀；避免在低区分度列单独建索引。
- 迁移：所有结构变更走版本化迁移脚本，向前兼容（先加列后删列）；生产库操作先备份并在维护窗口执行，禁止未经确认的破坏性 DDL。
- 查询：禁止无分页全表拉取；大表分页用游标/keyset；慢查询先看执行计划。
