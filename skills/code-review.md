# 代码审查清单

按四维度逐项检查：
1. 正确性：边界条件、空值、并发竞态、资源释放（defer/close）、错误传播链是否完整。
2. 安全性：外部输入是否校验/转义（SQL 注入、XSS、路径穿越）；凭据是否硬编码；危险命令是否有白名单。
3. 可维护性：命名是否自解释；函数是否单一职责；重复代码是否应提取；注释解释「为什么」而非「是什么」。
4. 风格：与项目现有风格一致（不引入新的格式化约定）；改动最小化，不顺手重构无关代码。

输出格式：【结论】(通过/需修改)、【问题】(按优先级 P0-P2 编号+位置+原因+建议)、【亮点】。
