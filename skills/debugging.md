# 系统化调试

1. 精确复现：记录最小复现步骤与完整报错（含堆栈、退出码、环境信息）。
2. 一次一个假设：为每个假设设计可证伪的验证（加日志/二分定位/最小用例），验证后再进入下一假设。
3. 二分法：输入、代码版本、依赖版本、配置项逐项二分缩小范围。
4. 根因修复：定位到根因层再改（不是表面打补丁）；修复后写回归测试。
5. 复盘：记录「错误轨迹」（失败日志/线索）到记忆，同类问题查历史。
