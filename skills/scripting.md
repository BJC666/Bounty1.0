# 脚本编写规范

- 首行说明用途与用法（注释块）；参数校验：缺参、非法值给出明确报错而非默默执行。
- 幂等性：重复执行结果一致（先检查再创建）；中途失败可安全重跑。
- 防误操作：危险路径操作前做目标校验与二次确认；用绝对路径或显式变量，不用未验证的拼接。
- 可观测：关键步骤打日志（时间/步骤/结果）；退出码语义明确（0 成功，非 0 分类失败）。
- 可维护：函数化、常量置顶；跨平台注意路径与编码；不在脚本里写密钥。
