# 性能优化方法

1. 测量先行：先定位真实瓶颈（CPU profile / 内存 profile / 慢查询日志 / 打点计时），不凭直觉优化。
2. 找大头：优先处理占用最大的热点；复杂度问题（O(n²)）先于常数优化。
3. 常见手段：缓存（含命中率监控）、批量与合并 IO、惰性计算、连接复用、索引优化。
4. 验证闭环：每项优化前后记录同一基准数据（耗时/内存/QPS），无收益的改动回退。
5. 克制：可读性优先于微小收益；为「将来」做的缓存/预取常是负资产。
