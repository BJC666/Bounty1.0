# 安全评审

对用户指定的代码范围执行以下评审清单，输出按风险分级：

## 高危（必须列出）
- SQL/命令注入：外部输入拼进 SQL、shell、eval 的位置
- 密钥泄露：硬编码 token/密码、日志打印凭据
- 危险命令：rm -rf、sudo、chmod 777、下载后直接执行
- 越权：缺少鉴权的管理接口、可被绕过路径穿越

## 中危
- 不安全的反序列化、正则 ReDoS、竞态写文件

## 输出格式
每条发现：`[严重度] 文件:行号 — 问题 — 修复建议`
最后给一句总体结论。只评审，不擅自修改代码。
